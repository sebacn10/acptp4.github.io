## TP4 — Migración a PHP y modularización

Se migraron las páginas informativas originales a PHP y se organizó la estructura utilizando archivos compartidos. `includes/header.php` contiene la cabecera y navegación; `includes/footer.php` centraliza el pie de página. Los títulos se pueden definir por página y el diseño queda separado en archivos de estilos.
